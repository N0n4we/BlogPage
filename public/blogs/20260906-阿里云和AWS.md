### 阿里云就是照葫芦画瓢，还画的不像

阿里云对标 AWS 很多产品，云监控 -> CloudWatch、配额中心 -> Service Quotas、RAM -> IAM、CloudSSO -> IAM Identity Center、事件总线 -> EB、etc.，而且产品定位都大差不差
但 AWS 是浑然一体的，阿里云可远观不可亵玩
以 EventBridge 为例，阿里云 EB 如果没有内置事件源，还要手动接入。比如阿里云 EB 不会采集云监控告警，但是又有 `cms:CloudMonitor:AlertWebHook` 这个内置事件源，导致我白白花了很长时间进行测试。而 AWS 就没有事件源这个概念，默认就把全平台的事件都在 EB 流通，包括 CloudWatch 报警。我觉得这才是 EB 的意义啊，**事件总线**，都 **总线** 了，平台事件还不默认采集，那我怎么不直接用消息队列
阿里云鸡肋的地方还有很多，包括但不限于 配额告警回调不带告警名称、有N个告警管理页面、RBAC不支持角色预配、etc.

---

从夯到拉锐评：阿里云只能给到人上人，AWS 必须夯爆了
